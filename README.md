# 🤖 BIRR-IA

## Inteligencia sin límites

Plataforma web de inteligencia artificial desarrollada
con Python, Streamlit y Google Gemini.

## Funcionalidades

- Chatbot con consejos personalizados.
- Comprensión del lenguaje natural.
- Análisis de artículos de investigación PDF.
- Generación de resúmenes inteligentes.
- Generación de código y scripts.
- Generación de música en texto.
- Generación de historias, guiones e ideas.
- Descarga de contenido generado.

## Tecnologías utilizadas

- Python
- Google Gemini API
- Streamlit
- PyPDF
- Visual Studio Code

## Instalación

Crear un entorno virtual:

    python -m venv venv

Activar el entorno virtual en Windows:

    .\venv\Scripts\Activate.ps1

Instalar las dependencias:

    python -m pip install -r requirements.txt

Crear un archivo .env utilizando .env.example
como referencia y agregar una API Key de Gemini.

## Ejecutar aplicación

    python -m streamlit run app.py

Abrir en el navegador:

    http://localhost:8501
